# Case Study 04 - AI Data Analyst Agent

> AI Data Analyst Agent je platformně nezávislý analytický framework určený pro strukturovanou analýzu business dat podle standardizovaného analytického postupu.

> Repozitář obsahuje funkční specifikaci agenta i kompletní referenční případovou studii, která ukazuje očekávaný průběh analýzy a podobu výsledného výstupu.

---

## Přehled

AI Data Analyst Agent vznikl jako součást projektu **AI Learning Journey**.

Cílem projektu bylo navrhnout analytického AI agenta, který nefunguje pouze jako generátor textu, ale dodržuje konzistentní analytické workflow podobné práci profesionálního datového analytika.

Agent klade důraz na:

- transparentnost,
- reprodukovatelnost,
- kvalitu dat,
- auditovatelnost,
- business interpretaci výsledků,
- jasné oddělení faktů od předpokladů.

# Analytické workflow

Agent postupuje podle standardizovaného workflow:

1. Business Understanding
2. Data Collection
3. Data Quality Assessment
4. Data Cleaning
5. Analysis
6. Validation
7. Reporting

Každý krok je dokumentován a reprodukovatelný.

---

# Principy návrhu

Projekt je postaven na následujících principech:

- Evidence-Based Analysis
- Data Quality First
- Transparency
- Reproducibility
- Traceability
- Auditability
- Business Value
